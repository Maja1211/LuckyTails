
# LuckyTails — Animal Adoption Platform

LuckyTails is a full-stack web application designed to connect animal shelters with people interested in adopting animals.

## Technologies

- Angular and TypeScript
- Node.js and Express
- MongoDB
- JWT authentication
- OpenStreetMap

## Key Features

- User registration and authentication
- Role-based access for adopters, shelters, and moderators
- Animal listings and search
- Scheduling visits to animal shelters
- Email verification
- Location-based features and map integration
- Serbian and English language support

## Project Structure

The application consists of a frontend, backend, and database.
